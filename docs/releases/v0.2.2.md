# Dreame Hub v0.2.2 — MOVA Home preview

## English

Validation: 61 Swift tests and three JavaScript regression suites passed. These checks do not establish real-device compatibility.

- Adds a **Dreame Home / MOVA Home** login selector with provider-specific routing, signing and session refresh.
- Preserves the selected provider in macOS Keychain and keeps older saved Dreame accounts compatible.
- Fixes saved-login selection: changing provider, username or server region requires re-entering the password; the old selection is no longer silently reused.
- Adds a MOVA identity catalog covering 22 families and 84 exact identifiers. Packed cleaning-mode handling is guarded by audited model IDs and device-reported station properties; unknown wetness scales are not overwritten.
- Keeps the existing menu-bar interface and adjusts compact login spacing for the additional provider field.

**MOVA has not yet been validated with a real account or robot.** Live login, maps, photos, physical controls and voice installation remain unverified. MOVA target navigation is not enabled. Offline tests are not real-device validation. No robot movement commands were issued for this update.

The public package uses neutral artwork; manufacturer PNGs with unverified redistribution rights are excluded. Existing Dreame read-only validation is documented separately and must not be interpreted as MOVA validation.

Download `Dreame-Hub-Swift-0.2.2-preview-arm64.dmg` for Apple Silicon, macOS 13+. This preview is ad-hoc signed and **not notarized by Apple**. [Installation and security guide](https://github.com/retoucheroz/dreamehub/blob/main/docs/INSTALL.md) · [MOVA scope](https://github.com/retoucheroz/dreamehub/blob/main/docs/MOVA.md).

## Türkçe

Doğrulama: 61 Swift testi ve üç JavaScript regresyon test paketi geçti. Bunlar gerçek cihaz uyumluluğu kanıtı değildir.

- Sağlayıcıya özel sunucu, imza ve oturum yenilemeyle **Dreame Home / MOVA Home** giriş seçimi eklendi.
- Seçilen sağlayıcı macOS Anahtar Zinciri'nde korunur; eski Dreame hesap kayıtları uyumlu kalır.
- Kayıtlı giriş düzeltildi: sağlayıcı, kullanıcı adı veya sunucu bölgesi değişince parola yeniden istenir; eski seçim sessizce kullanılmaz.
- 22 aile ve 84 tam kimlik içeren MOVA kataloğu eklendi. Birleşik temizlik modu incelenmiş kimlikler ve cihazın bildirdiği istasyon özelliğiyle sınırlandırılır; bilinmeyen ıslaklık ölçekleri ezilmez.
- Menü çubuğu tasarımı korundu; yeni sağlayıcı alanı için küçük giriş penceresinin boşlukları düzenlendi.

**MOVA henüz gerçek hesap veya robotla doğrulanmadı.** Canlı giriş, haritalar, fotoğraflar, fiziksel kontroller ve ses kurulumu doğrulanmamıştır. MOVA hedefe gitme açık değildir. Çevrimdışı testler gerçek cihaz doğrulaması değildir. Bu güncellemede robota hareket komutu gönderilmedi.

Herkese açık paket nötr görseller kullanır; yeniden dağıtım izni doğrulanmamış üretici PNG'leri dahil değildir. Mevcut Dreame yalnız-okuma doğrulaması MOVA doğrulaması anlamına gelmez.

Apple Silicon ve macOS 13+ için `Dreame-Hub-Swift-0.2.2-preview-arm64.dmg` dosyasını indirin. Önizleme ad-hoc imzalıdır; **Apple noter onayı yoktur**.
